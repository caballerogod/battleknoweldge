# AI Knowledge Battle

Интеллектуальная игра с двумя режимами, камерой, голосовым управлением и атмосферой телевизионного шоу.

**React + TypeScript + Vite · FastAPI · SQLite · MediaPipe · OpenAI**

## Два режима игры

| | «Битва знаний» | «Своя игра» |
| --- | --- | --- |
| Участники | Один игрок | Трое за общим экраном |
| Вопросы | Раунд из 10 вопросов из готового банка | 8 общих тем и поле из 40 вопросов |
| Сложность | Адаптируется к результатам | Стоимость от 100 до 500 очков |
| Ответы | Выбор одного из четырёх вариантов | Свободные ответы, загадки, варианты и вопросы с картинками |
| Прогресс | XP, уровни, достижения и статистика | Отдельный счёт каждого участника |
| AI | Платный API не нужен | Презентация без API или генерация своих тем с ИИ |

В обоих режимах доступны мышь, камера, голос и **30 секунд на ответ**. Устройства включаются только по желанию игрока.

## «Своя игра»

По умолчанию включена **«Презентация · без API»** — для выступлений и игры без оплаченного AI-баланса.

1. Введите три разных имени.
2. Выберите 8 тем из каталога 20 тем. Поиск понимает альтернативные названия: NBA, духи, сериалы.
3. При желании включите **резервный набор** — другие пять вопросов каждой темы.
4. Нажмите «Начать презентацию»: поле из 40 вопросов готово сразу.
5. Выбирайте клетку мышью, голосом или жестами; на ответ даётся 30 секунд.

Банк содержит **200 подготовленных вопросов**: 100 основных и 100 резервных, с эталонами, объяснениями и допустимыми вариантами ответа. Есть картинки, загадки и выбор из четырёх вариантов. Проверяется структура всех 200 вопросов и сборка случайных сочетаний тем; ошибочный основной набор темы автоматически заменяется резервным.

В презентации **генерация и проверка не вызывают AI и стоят $0**. Точное совпадение/подготовленный синоним засчитывается автоматически; варианты проверяются по выбранной кнопке. Другой свободный ответ фиксируется, таймер останавливается, ведущий видит эталон и выбирает «Засчитать», «Не засчитать» или «Снять вопрос без штрафа». Решение ведущего отображается на общем экране, поэтому обсуждайте его после фиксации ответа. Перезагрузка сохраняет партию, счёт и зафиксированный ответ.

Полный список тем и памятка ведущему: [режим презентации](docs/PRESENTATION_RU.md).

Кнопка **«Свои темы с ИИ»** сохраняет прежнюю генерацию восьми произвольных тем. Она требует настроенного провайдера и может потребовать исправлений/повторной подготовки; для выступления используйте подготовленный каталог.

Ход переходит следующему участнику после каждого завершённого вопроса. За правильный ответ начисляется стоимость клетки, за неправильный она вычитается. Пропуск, таймаут или снятый неоднозначный вопрос дают 0 очков.

**GPT-5.4** составляет вопросы и выполняет редактуру; **GPT-5.4-mini** проверяет смысл свободных ответов. Точные совпадения и варианты ответа сервер проверяет без дополнительного AI-запроса. Одобренные клетки сохраняются, исправления запрашиваются адресно. Вопросы с картинками используют локальный каталог иллюстраций.

Без API-ключа можно сыграть в **демонстрационную партию с готовыми темами**. Демо обозначено отдельно и не подменяет генерацию ваших тем.

## Быстрый запуск на Windows

Понадобятся **Python 3.11+**, **Node.js 22.12+**, npm и Git.

### 1. Скачайте проект

```powershell
git clone https://github.com/caballerogod/battleknoweldge.git
cd battleknoweldge
```

### 2. Установите зависимости

```powershell
powershell -ExecutionPolicy Bypass -File .\Setup.ps1
```

Скрипт создаст Python-окружение, установит backend и frontend, а также скопирует `.env.example` в `backend/.env`, если такого файла ещё нет.

### 3. Настройте AI (необязательно для презентации)

Откройте **`backend/.env`** и добавьте свой ключ:

```dotenv
AI_PROVIDER=openai
OPENAI_API_KEY=your_api_key_here
OPENAI_GENERATION_MODEL=gpt-5.4
OPENAI_REVIEW_MODEL=gpt-5.4
OPENAI_GRADING_MODEL=gpt-5.4-mini
```

Ключ хранится только на backend. **Не добавляйте его в frontend, коммиты или скриншоты.** После изменения настроек перезапустите backend. Генерация и проверка через OpenAI оплачиваются с API-баланса; стоимость зависит от объёма вопросов и количества исправлений. Приложение показывает оценку расходов по запросам, а не баланс аккаунта.

Для «Битвы знаний» и демонстрационной «Своей игры» ключ не нужен.

### 4. Запустите серверы

В первом терминале из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-Backend.ps1
```

Во втором терминале:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-Frontend.ps1
```

- **Игра:** http://127.0.0.1:5173
- **Документация API:** http://127.0.0.1:8000/docs

Для остановки нажмите `Ctrl+C` в каждом терминале.

## Камера и голос

Для игры с голосом используйте обычный **Chrome или Edge**. Во встроенном браузере доступ к микрофону может работать, а сервис распознавания речи — быть недоступным.

- **Голос:** например, «восьмая тема за двести», затем «подтвердить». Для вариантов — «первый»…«четвёртый»; для открытого вопроса произнесите сам ответ.
- **Жесты в «Своей игре»:** 1–5 пальцев выбирают тему, затем стоимость; кулак переключает группы тем 1–5 и 6–8; большой палец вверх подтверждает выбор. Перед повторением жеста смените позу или уберите руку.
- **Камера:** держите одну руку целиком в кадре при хорошем освещении. Распознавание MediaPipe выполняется в браузере; видео не отправляется на backend.

Распознавание речи зависит от возможностей браузера и может обращаться к его внешнему речевому сервису. Камера и микрофон не требуются для игры мышью.

## Сохранение и таймер

Backend создаёт `backend/battle.db` автоматически. Здесь хранятся профили, партии и прогресс. Журнал расходов AI хранится отдельно в `backend/ai_usage.db`.

Таймер контролируется сервером. Обновление страницы не выдаёт новые 30 секунд. До открытия вопроса таймер не идёт; после отправки ответ фиксируется на время проверки. Партию можно продолжить после обновления страницы.

Для резервной копии остановите backend и сохраните базы. В репозиторий они не входят, поэтому после клонирования на другом компьютере прежних игроков и партий не будет.

## Необязательный локальный AI

Проект также поддерживает Ollama с моделью `qwen3:4b-instruct`. Для этого режима:

```dotenv
AI_PROVIDER=ollama
OLLAMA_MODEL=qwen3:4b-instruct
```

Установите Ollama и запустите `Start-Local-AI.ps1`. В этом режиме `Start-Backend.ps1` также запускает помощник локальной модели. Веса скачиваются отдельно и не входят в GitHub-репозиторий.

Локальные вызовы не требуют оплаты OpenAI API, но на процессоре подготовка 40 вопросов может быть долгой. Качество зависит от выбранной модели. Автоматического переключения между Ollama и платным OpenAI нет. Основной режим в `.env.example` — **OpenAI**.

## Проверки

Из корня проекта:

```powershell
cd backend
..\.venv\Scripts\python.exe -m pytest tests -q
cd ..\frontend
npm.cmd test
npm.cmd run build
```

Последний проверенный набор: **96 backend-тестов и 112 frontend-тестов**, production-сборка успешна. Тесты backend используют временные базы и не требуют платных AI-запросов.


## Ограничения

AI может ошибаться в фактах и сложности вопросов. Структурная и редакторская проверки снижают риск, но не гарантируют правильность каждого вопроса; неподходящий комплект может быть отклонён.

Репозиторий предназначен для локального запуска. Публикация кода на GitHub сама по себе не размещает игру в интернете. Для публичного сервиса нужны отдельный хостинг frontend/backend, HTTPS, контроль доступа и ограничения расходов AI.

`.gitignore` исключает ключи, базы, журналы, установленные зависимости и результаты сборки. Для настройки используйте собственный `backend/.env`.
