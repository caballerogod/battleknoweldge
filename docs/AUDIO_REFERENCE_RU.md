# Разбор аудио указанного выпуска

Источник: [«Кто хочет стать миллионером», 18 ноября 2007](https://www.youtube.com/watch?v=Yzhau6No0KY), длительность 45:00. Выполнен разбор игровых событий по всему видеоряду, сменам подсветки ответов и автоматическому определению интервалов речи. Это карта событий и звуков для игры, не дословная расшифровка диалогов. Интервалы крупных блоков приблизительные, границы включённых аудиофрагментов — точные.

## Карта всего выпуска

| Время | События и звуковые роли |
|---|---|
| 00:00–00:29 | Заставка: музыкальная тема и вступление. |
| 00:29–02:00 | Представление участников, отборочный вопрос, проверка порядка ответов и выбор игрока. |
| 02:00–15:55 | Знакомство с первым игроком, вопросы, фиксация ответа, сигналы правильного ответа. Помощь зала около 06:40–07:10; звонок другу около 09:00. Неверный ответ около 15:41 и показ выигрыша. |
| 15:55–17:55 | Рекламный блок, возвращение в студию. Реклама не используется. |
| 17:55–27:55 | Второй отбор, знакомство со второй участницей, вопросы, правильные ответы и звонок другу около 25:30–26:10. |
| 27:55–28:45 | Рекламная вставка. Не используется. |
| 28:45–38:55 | Продолжение игры, фон размышления, фиксация и раскрытие ответов, рост суммы; ещё один звонок другу около 37:20. |
| 38:55–40:00 | Рекламная вставка и возвращение к игре. Реклама не используется. |
| 40:00–45:00 | Последние вопросы, фиксация последнего ответа около 44:13, раскрытие ошибки около 44:29, итоговый выигрыш и титры. |

## Что перенесено в приложение

| Событие приложения | Исходный фрагмент | Длительность | Файл |
|---|---|---|---|
| Начало нового раунда | 00:00.35–00:04.85 | 4,50 с | intro.wav |
| Ожидание ответа | 36:18.50–36:31.30 | 12,80 с, цикл | suspense.wav |
| Выбор варианта | 44:13.30–44:14.00 | 0,70 с | select.wav |
| Верный ответ | 09:32.28–09:36.08 | 3,80 с | correct.wav |
| Неверный ответ | 44:29.30–44:32.60 | 3,30 с | incorrect.wav |
| Время вышло | 44:29.30–44:31.90 | 2,60 с | timeout.wav |
| Последние десять секунд | 09:07.55–09:07.73 | 0,18 с | tick.wav |
| Дополнительный сигнал крупного верного ответа | 31:12.55–31:18.35 | 5,80 с | correct-major.wav |

Последний файл доступен для сравнения на странице прослушивания; автоматически в игре не запускается. В приложении нет телефонных подсказок, отбора игроков и рекламных пауз, поэтому отдельные джинглы этих событий не назначены существующим кнопкам. Короткий отсчёт взят из сцены звонка другу. Неверный ответ назначен также истечению времени: универсальный 30-секундный лимит каждого вопроса — правило приложения, а не выпуска.

## Обработка и ограничения

Нарезка сделана непосредственно из указанного ролика. Сохранены PCM WAV, mono, 32 кГц. Применены фильтры 65 Гц–12 кГц, усиление громкости, ограничитель пиков и короткие затухания краёв. Это не генерация похожей музыки и не студийные дорожки: запись эфира может содержать зал и фоновые шумы. Для рабочих фрагментов автоматическое определение речи и пробное распознавание не обнаружили разборчивых реплик; это не заменяет прослушивание человеком. Дополнительный музыкальный сигнал распознаватель ошибочно описал как «спокойная музыка».

Исходные границы и назначения сохранены в `frontend/public/audio/sources.json`. Воспроизводимая нарезка: `frontend/scripts/extract-reference-audio.py`; необходимы локальная запись и FFmpeg. Полный 45-минутный выпуск и инструменты анализа не включены в архив приложения. Права на материалы передачи принадлежат их правообладателям; проект не предоставляет отдельную лицензию на эти материалы.

Голосовые сообщения «Камера включена», «Микрофон включён», результаты и чтение вопроса остаются синтезом речи браузера. Голос ведущего не клонирован. При активном микрофоне фон и тики приостанавливаются; результат защищён существующей паузой распознавания. Таймер по-прежнему серверный, 30 секунд, без сброса при обновлении страницы.
